# BulkAPI — Bulk Assets API for JSM

Bulk create, update, delete, sync, and search Jira Service Management Assets
objects through a fast, key-secured REST API. Built on Atlassian Forge by
**Havibit OÜ**.

- [Troubleshooting](troubleshooting) — common errors and their fixes
- [Performance](performance) — measured bulk-vs-per-object numbers
- [Privacy policy](privacy-policy)
